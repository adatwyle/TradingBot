About this EA 
The Go Long EA does exactly what the name says: it only opens long positions. I personally use it on index CFDs because indices tend to grind toward new highs over time — economies grow, and so do the big indices. 
You define the opening and closing times, TP and SL levels, and you can restrict it to only open trades on a fresh daily high. Nobody can guarantee future returns — but as a systematic bet on long-term growth, it is a valid option.
